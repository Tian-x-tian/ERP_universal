# ERP 视觉风格基线（首页/登录页统一）

## 1. 视觉方向
- 主基调：政企数字化风格，表达“合规、协同、创新、绿色”。
- 色彩气质：蓝青主色，暖橙点缀，避免高饱和杂色和夸张对比。
- 画面层级：大面积渐变背景 + 半透明玻璃卡片 + 轻阴影。
- 图片语义：优先使用城市、产业、数据连接、协同网络等正向元素。

## 2. 颜色与变量
- 主题变量定义在 `src/styles/brand-theme.css`。
- 核心色：
  - `--erp-primary`: `#0d6fbe`
  - `--erp-primary-strong`: `#0a4f94`
  - `--erp-accent`: `#1cb9a0`
  - `--erp-warm`: `#ff8f4f`
  - `--erp-text`: `#1f2f46`
  - `--erp-muted`: `#5d6f85`

## 3. 组件风格规则
- 卡片：圆角、浅边框、悬浮阴影（避免硬边纯白块）。
- 主按钮：蓝青渐变背景，悬停提亮。
- 输入框/弹窗：统一中圆角，边框弱化，强调可读性。
- 表格：浅蓝头部和柔和 hover，减少“纯灰后台”感。

## 4. 页面结构建议
- 页面根容器优先使用 `erp-page`。
- 重要信息区优先使用 `erp-panel`（带边框和阴影）。
- 统计块建议包含：标题 + 数值 + 趋势说明，避免仅显示裸数字。

## 5. 图片与插画规范
- 统一参考登录页主视觉图：`src/assets/login-values-bg.svg`。
- 新增图片需保持同主题色和“协同治理”语义，不使用负面、冲突、娱乐化素材。
- 背景图优先服务可读性，不压文字对比度。
