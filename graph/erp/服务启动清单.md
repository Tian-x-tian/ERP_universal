# 服务启动清单

当前 ERP 后端有 7 个可运行 Spring Boot 服务：

| 服务 | 启动类 | 端口 |
|---|---|---:|
| erp-gateway | `GatewayApplication` | 9090 |
| erp-auth | `AuthApplication` | 9091 |
| erp-system | `SystemModuleApplication` | 9092 |
| erp-business | `BusinessApplication` | 9093 |
| erp-workflow | `WorkflowApplication` | 9094 |
| erp-ai | `AiModuleApplication` | 9095 |
| erp-saas-control | `SaasControlApplication` | 9096 |

`erp-system` 只保留 `SystemModuleApplication` 作为启动入口；`erp-modules/erp-system/pom.xml` 的 `spring-boot-maven-plugin` 也指定该主类。`SystemApplication` 是重复入口，已删除，避免 IDE Spring Boot 扫描结果混乱。

依赖模块如 `erp-common-core`、`*-client`、`*-contract`、`erp-parent`、`erp-modules` 不需要单独启动。

## 数据库连接

本地后端 YAML 的默认 MySQL host 已统一为 `192.168.0.22`，端口默认 `3306`，仍可通过 `MYSQL_HOST` / `MYSQL_PORT` 覆盖。`erp-auth`、`erp-system`、`erp-business`、`erp-workflow` 默认库为 `erp_system`；`erp-saas-control` 默认库为 `erp_saas_control`。

当前机器探测结论：

- `192.168.0.22:3306` 网络可达。
- `127.0.0.1:33317` 已用 `D:\software\mysql-8.0.17-winx64` 启动，数据目录为 `D:\workspace\ERP\.tmp\mysql-33317-data`，已创建 `erp_system_test` 和 `erp_saas_control` 两个空库。
- Nacos `127.0.0.1:8848` 可访问，但默认组未查询到 `erp-saas-control.yml`。

## SaaS SQL 初始化

`erp-saas-control` 启动时会先运行 `SaasControlSqlUpgradeRunner`，顺序为 `100`，默认扫描 `classpath:sql/upgrade/control/*.sql`，用 `saas_sql_upgrade_log` 记录脚本名、校验和和状态。随后运行 `SaasControlCatalogSchemaValidationRunner`，顺序为 `200`，按 manifest 校验 SaaS control 表结构。

`sql/init_control.sql` 只在 `SQL_INIT_MODE` 打开时由 Spring SQL init 执行；默认 `SQL_INIT_MODE=never`。版本化 upgrade 脚本包含 SaaS control 的建表和基础种子，正常启动 `erp-saas-control` 时应能补齐 `erp_saas_control` 库结构。本机 Nacos 的 `erp-saas-control.yml` 已指向 `192.168.0.22:3306/erp_saas_control`；其他后端服务 Nacos 配置当前仍指向 `127.0.0.1:33317/erp_system_test`。

共享库 `192.168.0.22:3306/erp_saas_control` 已确认初始化完成：`information_schema` 中有 15 张 `saas_%` 表；新增 `20260813_01_saas_default_platform_domain.sql` 补齐平台默认租户 `000000` 及其域名绑定（`localhost`、`127.0.0.1`），确保 Gateway 域名解析与登录正常通过。

## 安全密钥默认配置

所有服务 YAML 文件均已配置开发环境安全密钥默认回退值，单机直接启动无需显式设置环境变量：
- `ERP_INTERNAL_AUTH_SIGNATURE_SECRET`: `dev-internal-auth-signature-secret-must-be-32bytes!` (>=32 bytes)
- `ERP_SAAS_TENANT_ASSERTION_SIGNATURE_SECRET`: `dev-tenant-assertion-signature-secret-32b!` (>=32 bytes)
- `ERP_JWT_SECRET`: `dev-jwt-secret-must-be-at-least-64-bytes-long-for-hs512-local-development-environment!` (>=64 bytes)
