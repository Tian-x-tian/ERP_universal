# 维护指南

## 更新触发条件

ERP 相关任务完成前，若本次会话确认或改变以下内容，需要同步更新 `D:\workspace\ERP\graph\erp`：

- 模块边界、服务端口、Gateway 路由、接口契约。
- 登录、租户、权限、菜单、审计、安全边界。
- 数据库表、字段、初始化 SQL、升级 SQL、字典、权限数据。
- 前端路由、API 封装、菜单蓝图、核心页面流程。
- 重要风险、验证结论、排查经验、架构决策。

## 证据优先级

1. 当前源码、POM、YAML、SQL。
2. 当前测试、构建、运行和 Git 状态。
3. 历史记忆、旧代码索引和 `target` 产物仅作为线索。

## 更新原则

- 只更新与当前任务直接相关的笔记。
- 不把未经核实的历史信息写成当前事实。
- 收尾汇报说明是否更新图谱，以及更新了哪些文件。
